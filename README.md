# STM32 Nucleo-F411RE – GPIO Practice

## Board
STM32 Nucleo-F411RE

## MCU
STM32F411RETx (Cortex-M4)

## Features
- PA5 LED control (LD2)
- PC13 User Button (active low)
- Direct register programming (no HAL)

## Learning Goals
- RCC clock enable
- MODER configuration
- IDR vs ODR
- BSRR atomic operations
- Bitwise manipulation

## Build
STM32CubeIDE (non-CMake project)
